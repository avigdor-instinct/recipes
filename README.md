# מתכונים · CookFlow

ספריית מתכונים אישית ופתוחה, שנבנית מתוך בישול אמיתי במטבח והופכת כל מתכון לחוויית CookFlow: דף נוח בעברית עם מצב בישול, שלבים שאפשר לסמן, כמויות מודגשות, הקראה וטיימרים כשצריך.

הפרויקט התחיל ממתכונים אישיים שנאספו ועובדו, ובהם השפרדס פאי של אורי רון דגן ז״ל (מברלין), שנשמר כאן באהבה ולזכרו. בכל מתכון נשמרים הקול, הסיפור והייחוס המקוריים.

## האתר

הספרייה זמינה ב-GitHub Pages:

https://avigdor-instinct.github.io/recipes/

כל מתכון מקבל עמוד עצמאי ורספונסיבי שמתאים לטלפון, לטאבלט ולמחשב בזמן הבישול. דף הבית מתעדכן עם מתכונים חדשים.

## מפת דרכים

בהמשך מתוכננים ניווט בין מתכונים, הוספת מתכונים מתוך האתר, שינוי כמויות לפי מספר מנות, רשימות קניות, נתוני תזונה והתאמות תזונתיות. [מחקר best practices ומסלול המימוש](docs/roadmap-research.md).

## איך תורמים

אפשר להציע מתכון, תיקון או שיפור באמצעות Issue או Pull Request. לפני שמוסיפים מתכון של אדם אחר, חשוב לקבל רשות ולשמור ייחוס ברור. ההנחיות הקצרות נמצאות ב-[CONTRIBUTING.md](CONTRIBUTING.md).
